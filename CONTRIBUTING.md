# Contributing

Thanks for helping with Eight Files. Bug reports, new studies, grandmaster
profiles and test statement suggestions are all welcome.

## How to propose a change

1. Fork this repository and create a branch for your change.
2. Make your edits. There is no build step: open `index.html` in a browser to
   check that the page still works.
3. Open a pull request against `main` and describe what you changed and why.

All changes to `main` go through a pull request and need the maintainer's
approval before they are merged. The live site updates automatically once a
pull request is merged.

## Where things live

The README has a table of files and a "Common edits" section that covers
adding studies, adding grandmasters and changing test statements.

## Guidelines

- Keep the site static: no build tools and no server code.
- Load any new library from a public CDN, as the existing scripts do.
- Keep each pull request focused on one change.

## Reporting a bug

Open an issue and include what you did, what you expected and what happened.
If it involves your games, say which site they came from (Lichess or
Chess.com) and roughly how many games were loaded.
